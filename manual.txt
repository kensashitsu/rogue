1. はじめに
================================================================================

  Rogue は 1980 年代に生まれたダンジョン探索ゲームの元祖です。
  ターン制で進むため、プレイヤーが行動するまで時間は止まっています。
  マップはランダム生成されるため、毎回異なるダンジョンを探索できます。
  死亡するとセーブデータが消えます（パーマデス）。慎重に行動しましょう。

  【表示言語】
    英語と日本語を切り替えられます。名前入力画面で Tab、ゲーム中は「o」キー。
    選んだ言語は rogue.cfg に保存され、次回の起動時も同じ言語になります。
    日本語の字間が不揃いに見える場合は、Windows Terminal の設定で
    フォントを「BIZ UDゴシック」など日本語を含む等幅フォントにしてください。

================================================================================
2. ゲームの目的
================================================================================

  地下26階に隠された「イェンダーの魔除け（Amulet of Yendor）」を
  取得して地上に生還することが目的です。

  魔除けを持たずに地上（1階より上）へ出ようとすると失敗します。
  魔除けを取得後は「<」コマンドで階段を上り、1階から地上を目指してください。

  【初期装備】
    プレイヤーは以下を持ってゲームを開始します。
      ・+1,+1のメイス（装備済み）
      ・+1,+0のショートボウ（パック内）
      ・矢 25〜39 本（パック内）
      ・+1のリングメイル AC6（装備済み）
      ・食料 1 個（パック内）

3. 画面の見方
================================================================================

  画面は80×24文字で構成されます。

  ┌──────────────────────────────────────────────────────────────────────────────┐
  │ 金貨を42枚拾った。                                  ← メッセージ行 (Row 0)  │
  │ ┌───────────────────────┐                                                    │
  │ │ ─────────────── . . . │                                                    │
  │ │ │       @      │ # . .│  ← ダンジョンマップ (Row 1〜22)                   │
  │ │ │              │ #    │                                                    │
  │ │ └──────────────┘      │                                                    │
  │ 階:1  金:42  HP:12(12)  力:16(16)  防:7  経験:1/0        ← ステータス行    │
  └──────────────────────────────────────────────────────────────────────────────┘

  【マップ記号一覧】
    @    プレイヤー（あなた）
    .    部屋の床
    #    通路
    +    ドア
    ─ │  壁
    %    階段（> で下へ / < で上へ）
    ^    トラップ（罠）
    *    金貨
    !    薬
    ?    巻物
    :    食料
    )    武器
    ]    防具
    =    指輪
    /    杖
    ,    イェンダーの魔除け
    A〜Z モンスター

  【ステータスバー】
    階:X      現在の階層（フロア番号）
    金:X      所持金貨数
    HP:X(X)   現在HP（最大HP）
    力:X(X)   現在筋力（最大筋力）
    防:X      実効アーマークラス（小さいほど硬い）
    経験:X/X  プレイヤーレベル / 累積経験値

  空腹状態・状態異常はステータスバーの末尾に略称で表示されます。
    空腹 / 衰弱 / 飢餓        空腹状態（詳細は「7. 空腹と食料」参照）
    混乱 / 盲目 / 麻痺 など   状態異常（詳細は「11. 状態異常」参照）

  複数メッセージがある場合は末尾に「--続く--」と表示されます。
  スペースキーで次のメッセージへ進みます。

4. 基本操作
================================================================================

  【移動】
    vi キー（ローグライク標準）:
      y  k  u
      h  @  l
      b  j  n

      k = 北     j = 南     h = 西     l = 東
      y = 北西   u = 北東   b = 南西   n = 南東

    矢印キー:
      ↑↓←→ = 北南西東

    テンキー（NumLock ON 時）:
      7 8 9
      4 5 6   （5 = 待機）
      1 2 3

    テンキー（NumLock OFF 時）:
      Home/PgUp/End/PgDn = 斜め移動

  【走行（大文字）】
    H J K L Y U B N = 壁・ドア・モンスターに当たるまで走り続ける

  【足元にモンスターがいる場合】
    移動コマンドでその方向にモンスターがいると自動的に攻撃します。

5. コマンド一覧
================================================================================

  【移動・行動】
    h j k l y u b n   8方向移動（vi キー）
    H J K L Y U B N   8方向走行
    矢印キー           4方向移動
    テンキー           8方向移動（5=待機）
    .                 1ターン休憩
    Z                 治るまで休む（盲目・幻覚・混乱などが治り、HPが満タン
                      になるまで休み続ける。何か起きたら止まる）
    s                 隣接マスを探索（隠しドア・トラップ発見）
    f                 指定方向のモンスターへ接近攻撃
    >                 下り階段を降りる（足元に % が必要）
    <                 上り階段を登る（足元に % が必要）

  【アイテム操作】
    i    インベントリを開いてアイテムを使用
    d    アイテムを床に捨てる
    e    食料を食べる（: のアイテム）
    r    巻物を読む（? のアイテム）
    q    薬を飲む（! のアイテム）
    w    武器を装備する（) のアイテム）
    W    防具を着る（] のアイテム）
    T    武器または防具を外す
    P    指輪をはめる（= のアイテム）
    R    指輪を外す
    t    アイテムを投擲する（方向を指定）
    z    杖を使う（/ のアイテム / 方向を指定）

  【情報・システム】
    ?    ヘルプを表示（日本語キーボードの場合は F1 でも可）
    F1   ヘルプを表示（? の代替）
    @    キャラクターのステータス詳細を表示
    /    シンボルの意味を調べる
    ^    足元のトラップを確認
    Ctrl-P   直前のメッセージを再表示
    Ctrl-R   画面を再描画
    o    表示言語を切り替える（英語 / 日本語。次回の起動時も同じ言語になる）
    S    セーブして終了
    Q    ゲームを放棄して終了（スコアは記録されるが死亡扱い）

  ※ 装備（w/W/P）・取り外し（T/R）・投擲（t）・杖（z）はすべて1ターン消費します。
  ※ 「i」でインベントリを開くとアイテムを直接使用できます。
     種別ごとのコマンド（e/r/q/w/W など）を使う場合は該当種別のみ表示されます。

6. ステータス
================================================================================

  【HP（ヒットポイント）】
    0 になると死亡。戦闘していないとターン経過で自然回復する。
      Lv1〜7:  しばらく戦わずにいると1ずつ回復（Lv1 で約19ターンに1、Lv7 で約7ターンに1）
      Lv8以上: 3ターン戦わずにいると、毎ターン 1〜(Lv−7) 回復
    攻撃した・された時点で回復の待ち時間はリセットされる。
    再生の指輪1個につき毎ターン+1。

  【力（STR・筋力）】
    攻撃命中・ダメージボーナスに影響。
    現在値（括弧の外）と最大値（括弧の内）の二本立て。
    毒・ラトルスネークの咬傷で現在値が一時的に低下（最大値は下がらない）。
    筋力増強の薬で最大値が +1 上昇。
    筋力回復の薬で現在値を最大値まで回復。

    STR と命中/ダメージボーナスの目安（最大STR: 31）:
      STR  3〜 5:  命中-3〜-1 / ダメージ-3〜-1
      STR  6〜13:  ボーナスなし
      STR 14〜15:  命中+1    / ダメージ+0〜+1
      STR 16〜18:  命中+2    / ダメージ+1〜+2
      STR 19〜21:  命中+2〜+3 / ダメージ+2〜+3
      STR 25〜26:  命中+6〜+7 / ダメージ+5〜+6
      STR 27〜31:  命中+7〜+10 / ダメージ+7〜+10

  【防（AC・アーマークラス）】
    低いほど防御力が高い。初期値10（裸）。
    防具を着ることで低下する。

    防具ごとの基本AC:
      革鎧              8
      リングメイル      7
      鋲打ち革鎧        7
      スケイルメイル    6
      チェインメイル    5
      スプリントメイル  4
      バンデッドメイル  4
      プレートメイル    3

  【プレイヤーレベルと経験値】
    モンスターを倒すと経験値を獲得。一定値に達するとレベルアップ。
    レベルアップ時は最大HP が 3〜12 ランダムで増加（原作の 1〜10 に +2）。最大レベルは 20。

    必要経験値（累積）:
      Lv2:10  Lv3:20  Lv4:40  Lv5:80   Lv6:160   Lv7:320   Lv8:640
      Lv9:1300  Lv10:2600  Lv11:5200  Lv12:13000  Lv13:26000  Lv14:50000
      Lv15:100000  Lv16:200000  Lv17:400000  Lv18:800000  Lv19:2000000
      Lv20:4000000

7. 空腹と食料
================================================================================

  プレイヤーは毎ターン食料を消費します。
  消費速度は「基本1 + 装備中の指輪ごとの消費」。魔除け所持中は基本が0になる。
    1/ターン:   守り・筋力・筋力維持・忍び足・鎧維持
    2/ターン:   再生
    たまに1:    探索・器用さ・攻撃力（1/3）、透視（1/5）
    0:          飾り・怪物刺激・テレポート
    消化遅延:   1/2 の確率で消費を1減らす

  【空腹状態の表示】
    空腹になるとステータスバーおよびメッセージで通知されます。

    表示  メッセージ                    症状
    ────────────────────────────────────────────────────────────────────
    空腹  「お腹が空いてきた。」        特になし（残り300未満）
    衰弱  「空腹で体に力が入らない。」  特になし（残り150未満）
    飢餓  「空腹のあまり気を失った。」  食料が尽きると時々気絶して
                                        数ターン動けなくなる。
                                        さらに850ターン食べないと餓死

  【食料の食べ方】
    「e」コマンドまたは「i」でインベントリを開いて食料（:）を選択。
    満腹時は食べられない（最大容量: 2000）。

  【食料の種類】
    食料                通常の食料。70%の確率でまずく、30%でおいしい。
                        どちらの場合も食料値は十分補給される。
    粘菌                食べ物の一種。常においしく、経験値+1を得る。

8. 戦闘
================================================================================

  【プレイヤーの攻撃】
    移動方向にモンスターがいると自動攻撃。
    命中判定: d20 + プレイヤーレベル + 命中ボーナス >= 21 − モンスターAC
    ダメージ: 装備武器のダイス＋ダメージボーナス（素手: 1d4）

  【武器ダメージ】（近接ダメージ / 投擲ダメージ）
    メイス            2d4 / 1d3    ロングソード      3d4 / 1d2
    ショートボウ      1d1 / 1d1    矢                1d1 / 2d3
    ダガー            1d6 / 1d4    両手剣            4d4 / 1d2
    ダーツ            1d1 / 1d3    手裏剣            1d2 / 2d4
    槍                2d3 / 1d6

  【武器表示の見方】
    「+1,+2のロングソード」 → 命中ボーナス+1、ダメージボーナス+2のロングソード
    「+0,+0のメイス」       → 付与魔法なしの通常のメイス（基本ダメージ2d4は変わらない）

  【モンスターの攻撃】
    命中判定: d20 + モンスターレベル >= 21 − プレイヤー実効AC

  【投擲攻撃】
    「t」コマンドでアイテムを投げる。
    ショートボウを装備中に矢を投げると命中・ダメージに弓のボーナスが加算される。
    命中した矢は消滅し、外れた矢のみ着地点に落ちて回収できる。

  【セービングスロー】
    特殊攻撃を受けた際、d20 + セーブ値 >= 14 + 難易度 で効果を避けられる。
    プレイヤーレベルが高いほど成功しやすい。
    守りの指輪を装備するとセーブ値にボーナスが加算される。

9. アイテム
================================================================================

  薬（!）と 巻物（?）と 指輪（=）と 杖（/）は
  正体不明の外観（色・タイトル・宝石・素材）で拾います。
  使用すると正体が判明します。

  ────────────────────────────────────────────────────────────────────────────
  【薬（!）】  「q」コマンドで飲む

    名前                   効果
    ───────────────────────────────────────────────────────
    混乱                   混乱状態になる（有害）
    幻覚                   幻覚状態になる（モンスターや物が別の文字に見える・約300ターン続く）
    毒                     現在STRが低下する（有害）
    筋力増強               最大STRが1増加（現在STRも同量増加）
    透視                   不可視モンスターを一定ターン見えるようになる
    回復                   HPを回復（失明も治癒）
    特効回復               HPを大量回復（混乱・失明も治癒）
    加速                   一時的に加速（1ターンに2回行動）
    筋力回復               現在STRを最大値まで回復
    レベルアップ           強制的にレベルアップ
    怪物感知               フロア上のモンスターを感知（マップに重ねて表示）
    魔力感知               フロア上のアイテムの位置を感知（マップに重ねて表示）
    盲目                   盲目状態になる（有害・約300ターン続く）
    浮遊                   浮遊状態になる（トラップを踏まなくなる）

  ────────────────────────────────────────────────────────────────────────────
  【巻物（?）】  「r」コマンドで読む

    名前                   効果
    ───────────────────────────────────────────────────────
    怪物混乱               次の攻撃で相手を混乱させる
    地図                   フロア全体のマップを開示
    金縛り                 周囲2マス以内の追ってくるモンスターを止める
                           （攻撃するまで動かない）
    睡眠                   プレイヤーが一時眠る（有害）
    鎧強化                 防具のACを1改善、呪いを解除
    武器強化               武器の命中またはダメージを+1改善
    識別                   インベントリ内の任意のアイテム1個の正体を判明させる
                           （薬・巻物・武器・防具・指輪・杖すべて対象）
                           ※ ESCでキャンセル可能。その場合、巻物は消費されない。
    怪物退散               床に置くとモンスターが近寄らなくなる
                           ※ 読んでも笑い声が聞こえるだけ（読むと無駄になる）
                           ※ 一度拾って落とした巻物に触れると消滅する
    食料感知               フロア上の食料の位置を感知
    テレポート             ランダムな位置に瞬間移動
    怪物召喚               近くにモンスターを召喚（有害）
    解呪                   装備中の呪いをすべて解除
    鎧保護                 現在装備中の防具を永続的に保護（アクエイターの腐食・錆の罠を無効化）
    怪物刺激               全モンスターが攻撃的になる（有害）

  ────────────────────────────────────────────────────────────────────────────
  【武器（)）】  「w」コマンドで装備 / 「T」で外す

    同時に1本まで装備可能。
    呪われた武器は外せない（解呪の巻物が必要）。
    「t」コマンドで投擲も可能。

  ────────────────────────────────────────────────────────────────────────────
  【防具（]）】  「W」コマンドで装備 / 「T」で外す

    同時に1着まで装備可能。
    カッコ内の数値が実際のAC（小さいほど防御力が高い）。
    呪われた防具は外せない（解呪の巻物が必要）。

  ────────────────────────────────────────────────────────────────────────────
  【指輪（=）】  「P」コマンドで装着 / 「R」で外す

    両手に1個ずつ、計2個まで装備可能。
    呪われた指輪は外せない（解呪の巻物が必要）。
    指輪の種類ごとに食料消費が増える（「7. 空腹と食料」参照）。

    名前                   効果
    ───────────────────────────────────────────────────────
    守り                   ACが改善（強化値の分）、セービングスローにもボーナス
    筋力                   STRが増加（強化値の分）
    筋力維持               現在STR保護（ラトルスネーク・毒による低下を防ぐ）
    探索                   毎ターン自動探索（隠しドアを自動発見）
    透視                   不可視モンスターが常に見える
    器用さ                 命中ボーナスが上昇
    攻撃力                 ダメージボーナスが上昇
    再生                   毎ターンHP+1（自然回復に加算）。食料消費が多い
    消化遅延               1/2 の確率で食料消費を1減らす
    忍び足                 凶暴(M)モンスターが同室で目覚めなくなる
    飾り                   何もしない装飾品
    怪物刺激               全モンスターが目覚めて追跡する（必ず呪い付き）
    テレポート             毎33ターンに1回ランダムテレポートが発生（必ず呪い付き）
    鎧維持                 防具の錆・腐食を無効化

  ────────────────────────────────────────────────────────────────────────────
  【杖（/）】  「z」コマンドで使用（方向指定あり）

    使うたびに充填数が1減少。識別後は「［残りX回］」で充填数が表示される。
    短い杖と杖があり、種類ごとにどちらかに決まっている。

    名前                   効果
    ───────────────────────────────────────────────────────
    光                     現在の部屋を明るくする（短い杖）
    透明化                 モンスターを不可視にする（短い杖・はずれ）
    稲妻                   電撃のボルトを放つ（短い杖）
    炎                     炎のボルトを放つ（短い杖）
    冷気                   冷気のボルトを放つ（短い杖）
    魔法の矢               魔法のミサイルを放つ（短い杖）
    変身                   モンスターを別のモンスターに変化させる（杖）
    怪物加速               モンスターを加速させる（杖・使わないこと）
    怪物減速               モンスターを減速させる（杖）
    生命吸収               自分のHP//2を失い、フロア上の全モンスターに
                           同量ダメージを個別に与える（短い杖）
                           ※ モンスター不在時は自分のHPも減らず識別もされない
                           ※ 自分のHP が 1 以下では使用不可
    追放                   モンスターをランダムテレポート（杖）
    引き寄せ               モンスターをプレイヤー隣接に呼び寄せる（杖）
    無力化                 モンスターの特殊能力を無効化（短い杖）
    無                     何もしない（はずれ・短い杖）

  ────────────────────────────────────────────────────────────────────────────
  【食料（:）】  「e」コマンドで食べる
    食料・粘菌の2種類。

  【金貨（*）】  踏むと自動収集（インベントリ不使用・上限なし）

  【トラップ（^）】
    床と同じ見た目で隠されており、踏んだ瞬間に ^ が現れて効果が発動する。
    「s」コマンドで隣接マスのトラップを発見できる（発動しない）。
    「^」コマンドで足元のトラップ種別を確認できる。
    浮遊状態ではすべてのトラップを回避できる。

    名前                   効果
    ───────────────────────────────────────────────────────
    落とし穴               1階下に落下する
    矢の罠                 矢が飛んでくる（命中判定あり、1d6ダメージ）
                           ※ 外れた矢は床に落ちて回収できる
    眠りガスの罠           5〜9ターン麻痺（行動不能）
    トラバサミ             3〜5ターン麻痺（行動不能）
    テレポートの罠         フロア内のランダムな位置に飛ばされる
    毒矢の罠               1d4ダメージ＋VS_POISON セーブ失敗で現在STR -1
                           筋力維持の指輪の装備中は STR 低下を防ぐ
    錆の罠                 装備防具 AC +1 悪化
                           ※ 革鎧は錆びない（免疫）
                           ※ 鎧保護の巻物を使った防具・鎧維持の指輪で無効
    謎の罠                 上記の落とし穴〜錆の罠のいずれかをランダムに発動

  【イェンダーの魔除け（,）】
    26階に1個存在するゲームのゴールアイテム。インベントリに収納して運ぶ。

11. 状態異常
================================================================================

  状態異常はステータスバーの右側に略称で表示されます。

  表示    症状と対処法
  ─────────────────────────────────────────────────────────────────────────────
  混乱    移動・アイテム使用方向がランダムになる。
          時間経過または回復の薬で回復。
  盲目    マップが見えず、隣接マスしか認識できない。
          時間経過または回復・特効回復の薬で回復。
  麻痺    一切行動できない（キー入力しても空ターンになる）。
          時間経過で回復。アイスモンスター・睡眠の巻物・気絶に注意。
  幻覚    モンスター・アイテムがランダムな文字で表示される。
          時間経過で回復。
  毒      毎ターン現在STRが1低下。時間経過または筋力回復の薬で回復。
          ※ STRが3以下になると毒の減少は停止する
  加速    1ターンに2回行動できる（食料や状態異常の時間は1ターン分）。
          時間経過で自然に解除される。
  減速    2ターンに1回しか行動できない（モンスターが2回動く）。
          時間経過で自然に解除される。
  浮遊    すべてのトラップを踏み越えられる。
          ISMEAN モンスターが反応しにくくなる。
          浮遊の薬で発生する。時間経過で解除。
  透明    プレイヤーが不可視になる（CANSEE 持ちでなければ追跡されない）。
  拘束    フライトラップに捕まっている状態。移動不可・攻撃は可能。
          フライトラップを倒すか離れれば解除される。

12. セーブとスコア
================================================================================

  【セーブ】
    「S」コマンドで確認後にセーブして終了します。
    次回起動時に自動でセーブデータを読み込みます（タイトル画面をスキップ）。
    死亡するとセーブデータは削除されます（パーマデス）。
    ウィンドウを閉じた場合も自動セーブされます。

  【ゲームの放棄（Q）】
    「Q」コマンドで確認後にゲームを放棄できます。
    セーブは行われず、スコアが記録されて終了します（死亡扱い）。

  【スコア計算】
    スコア = 所持金 + 累積経験値
    （勝利時はプレイヤーレベル×100が加算されます）

  【ハイスコア】
    上位10件が rogue.scr ファイルに保存されます。
    死亡時・放棄時・ゲームクリア時に自動登録されます。
    ゲーム終了後にハイスコア一覧が表示されます。

  【ゲームオーバーログ】
    死亡時の詳細（死因・最終ステータス・直近のメッセージ）が
    gameover.log ファイルに記録されます。

13. ヒントと攻略
================================================================================

  【初心者向け基本戦略】

  ○ 食料不足に注意
    空腹状態（空腹→衰弱→飢餓）はゲームオーバーの主な原因のひとつです。
    食料（:）を見つけたら積極的に拾っておきましょう。
    消化遅延の指輪があれば装備しましょう。
    指輪は種類によって食料消費が増えるので注意（再生の指輪は特に多い）。

  ○ 戦闘は慎重に
    複数のモンスターに囲まれると一気に危険になります。
    通路（#）でモンスターを一列に引き付けて1対1で戦いましょう。
    HPが少なくなったら逃げることも重要です。
    HPはターン経過で自然回復しますが、戦闘中は回復が追いつかない場合があります。

  ○ 薬を惜しみなく使う
    回復・特効回復の薬は危機的状況で使いましょう。
    正体不明の薬を試す場合はHPに余裕があるときに。

  ○ 巻物を活用する
    地図の巻物はフロアの構造を把握できる非常に有用な巻物です。
    武器強化・鎧強化の巻物は早めに使って戦闘力を上げましょう。
    識別の巻物は指輪・杖・薬・武器・防具すべてを識別できます。

  ○ モンスターの特性を知る
    - レプラコーン (L): 金貨を奪われてもアイテムは無事。倒すと返ってくる。
    - ニンフ (N): アイテムを盗まれる。倒すと取り戻せる。大事なアイテムは先に床に置く手もある。
    - アイスモンスター (I): 2〜11階から出現する。ヒットで 2〜3 ターン凍結するが
                       直接HPダメージはない。AC9で当たりやすい。麻痺中はモンスターに
                       攻撃され続けるため、周囲のモンスター数に注意。
    - アクエイター (A): 防具が腐食する。鎧保護の巻物で防具を保護しておくとよい。
    - レイス (W): 15% でレベルドレイン。経験値 0 のときは即死。遠距離攻撃か回避推奨。
    - フライトラップ (F): 一度掴まれると毎ターン1d6のダメージを受け続ける。
                          無力化の短い杖や隣接マスからの攻撃で倒すこと。
    - ファントム (P): 15〜24階に出現する不可視モンスター。透視の効果がないと
                   「何か」としか表示されない。攻撃はできるが命中が難しい。
    - ドラゴン (D): 一直線上にいると遠くから炎（6d6）を吐いてくる。
                  縦横斜めの線から外れて近づくこと。無力化の短い杖で炎を封じられる。

  ○ 未識別アイテムの扱い
    薬・巻物・指輪・杖は拾っただけでは正体不明です。
    - 巻物は比較的安全に試せる（悪い効果もあるが致命的なものは少ない）
    - 薬はHP満タン時に試す
    - 指輪は呪われていると外せないので注意。解呪の巻物で解除可能。
    - 識別の巻物があれば先に使うと安全。

  ○ ゼロック (X) に注意
    アイテムに変装するモンスターです。
    知らないうちにアイテムを拾おうとして攻撃されることがあります。

  ○ 探索コマンド「s」を活用する
    「s」を押すと隣接マスの隠しドアやトラップを発見できます（発動しない）。
    行き止まりに見えても隠しドアがある場合があります。
    探索の指輪を装備すると毎ターン自動探索される。

  ○ 弓と矢の活用
    ショートボウを装備した状態で矢を投げると弓のボーナスが加算される。
    モンスターに命中した矢は消えるが、外れた矢は床に落ちて回収できる。
    ダーツや手裏剣は弓なしでもそのまま投擲できる。

  ○ 深階での注意
    26階（AMULETLEVEL）を超えると全モンスターがスケールアップされます。
    魔除け取得後はできるだけ戦闘を避けて素早く帰還しましょう。
    帰還中は上り階段（< キー）を使います。
    浮遊中は下り階段を降りられないので注意。
    1階で < を押すとゲームクリア（魔除け所持が必要）。
